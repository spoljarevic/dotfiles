## Where to find them ##
I make regular backups from my Pictures, including wallpapers, to my Proton drive.

To download them, simply follow [this link](https://drive.proton.me/urls/RXH41Q9TH8#AkzIN0kpCEIL) and type in the password ``SpoljarevicsDotfileWallpapers@07-04``.

I set up a password since I don't want AI bot scrapers scan for general links and attack mine.

After that, simply download all the wallpapers as a zip file and use a tool like ``unzip`` to extract them, or just download the ones you like the most.
